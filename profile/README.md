## The AI agent cloud, in the open

[E2B](https://e2b.dev/?utm_source=github&utm_medium=referral&utm_campaign=readme&utm_content=org) gives every agent session an isolated Linux machine that boots from a snapshot and works with any model or agent framework. You ship the agent. We run the infrastructure. Our cloud or yours.

Every layer is public under Apache-2.0: the Firecracker runtime, the control plane, the in-VM agent, the SDKs, and the dashboard. The code on E2B Cloud is the code in these repositories.

### Start here

```bash
npm i e2b        # JavaScript / TypeScript
pip install e2b  # Python
```

```python
from e2b import Sandbox

with Sandbox.create() as sandbox:
    result = sandbox.commands.run('echo "Hello from E2B!"')
    print(result.stdout)
```

Get an API key at [e2b.dev](https://e2b.dev/?utm_source=github&utm_medium=referral&utm_campaign=readme&utm_content=org), then follow the [quickstart](https://docs.e2b.dev/quickstart).

### The stack

| Repository | What it is |
|---|---|
| [**runtime**](https://github.com/e2b-dev/runtime) | The runtime behind every E2B stack. Control plane, Firecracker orchestrator, in-VM agent, edge router, and template builder. Go. Includes **Embed**, the whole stack on one machine you own. |
| [**E2B**](https://github.com/e2b-dev/E2B) | The core SDK and CLI for JavaScript and Python. Create sandboxes, run commands, move files, expose ports. |
| [**code-interpreter**](https://github.com/e2b-dev/code-interpreter) | SDK for running AI-generated code with stateful Jupyter-style execution, charts, and streaming output. Built on E2B. |
| [**desktop**](https://github.com/e2b-dev/desktop) | Sandboxes with a graphical desktop for computer-use agents. Screenshots, mouse, keyboard, VNC streaming. |
| [**dashboard**](https://github.com/e2b-dev/dashboard) | Open-source dashboard for a runtime you host yourself. Sandboxes, templates, and builds behind a team API key. |

### Build with it

| [**surf**](https://github.com/e2b-dev/surf) | A computer-use agent that drives an E2B desktop through natural language. |

| [**e2b-cookbook**](https://github.com/e2b-dev/e2b-cookbook) | Examples and guides for every major model provider and agent framework. |
